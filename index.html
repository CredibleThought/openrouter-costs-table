Words match the model id, name and features. Juxtaposed words are AND. Operators: AND, OR, NOT, -word, !word, &&, ||, parentheses and "quoted phrases".
Number filters: a field, an operator (> >= < <= =) and a number, e.g. intel>40, in<1, ctx>=200k, private=1. Money is USD. A model with no value never matches.
